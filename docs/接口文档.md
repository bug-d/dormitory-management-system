# 接口文档

后端上下文路径为 `/api`，除登录和接口文档外均需携带：

```http
Authorization: Bearer <JWT>
```

## 认证

- `POST /api/auth/login`：登录。
- `POST /api/auth/logout`：登出。
- `POST /api/auth/refresh`：刷新 Token。
- `GET /api/auth/current-user`：当前用户。
- `PUT /api/auth/change-password`：修改密码。

## 管理员

- `/api/admin/users/**`：用户管理。
- `/api/admin/students/**`：学生管理。
- `/api/admin/dorms/**`：宿舍管理。
- `/api/admin/audit/**`：申请审核与入住查询。

## 宿舍管理员

- `GET /api/manager/dorms/page`：分页查询管辖宿舍。
- `GET /api/manager/dorms/{id}/residents`：查询入住人员。
- `GET /api/manager/dorms/{id}/history`：查询入住历史。
- `GET /api/manager/audit/pending`：查询管辖范围待审核申请。
- `PUT /api/manager/audit/audit`：审核单条申请。
- `PUT /api/manager/audit/batch-approve`：批量通过。
- `PUT /api/manager/audit/batch-reject`：批量驳回。

## 学生

- `GET /api/student/dorms/available`：可选宿舍。
- `POST /api/student/apply-checkin`：入住申请。
- `POST /api/student/apply-transfer`：调宿申请。
- `GET /api/student/my-dorm`：当前宿舍与室友。
- `PUT /api/student/leave-dorm`：退宿。
- `GET /api/student/applications`：申请历史。

完整 OpenAPI 页面在后端启动后的 `/api/doc.html`。
