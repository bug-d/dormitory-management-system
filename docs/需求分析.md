# 需求分析

## 角色

- 系统管理员：管理用户、学生、宿舍，查看全局统计并处理所有申请。
- 宿舍管理员：查看获授权宿舍、入住人员和历史，并审核管辖范围内的申请。
- 学生：查看个人信息和可用宿舍，提交入住/调宿申请，查看申请记录并办理退宿。

## 核心流程

1. 用户登录后获得 JWT，前端根据角色显示对应菜单。
2. 学生选择符合性别和容量限制的宿舍并提交申请。
3. 管理员或拥有完全控制权限的宿管审核申请。
4. 申请驳回或撤销时释放预留床位；入住和退宿同步更新宿舍容量。

## 安全与质量要求

- 所有管理接口必须经过角色授权，宿管接口还必须校验具体宿舍权限。
- 密码使用 BCrypt，随机密码使用安全随机数。
- 日志不得包含明文密码、密码哈希、完整 Token 或数据库凭据。
- 生产配置通过环境变量注入。
