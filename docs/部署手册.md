# 部署手册

## 环境要求

- JDK 17
- Maven 3.9+
- Node.js 18+
- MySQL 8

## 配置

以下变量必须由部署平台注入：

- `DB_URL`
- `DB_USERNAME`
- `DB_PASSWORD`
- `JWT_SECRET`（至少 32 个随机字符）
- `JWT_EXPIRATION`（可选，默认 86400000）

不要将 `.env` 或生产凭据提交到仓库。

## 数据库

首次部署依次执行 `database/schema.sql`、`database/data.sql`。生产环境应审查并替换演示账号。

## 构建

```powershell
cd backend
mvn clean package

cd ..\frontend
npm.cmd ci
npm.cmd run build
```

后端产物位于 `backend/target`，前端静态产物位于 `frontend/dist`。

## 上线检查

- 后端进程使用 JDK 17。
- 前端 API 地址指向正确的 `/api` 网关。
- HTTPS 已启用，数据库不暴露公网。
- JWT 密钥不是示例值，日志级别不输出敏感内容。
- 演示账号已删除、禁用或更换密码。
